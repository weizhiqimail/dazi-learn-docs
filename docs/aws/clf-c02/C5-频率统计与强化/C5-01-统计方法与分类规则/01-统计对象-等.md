# C5-01-统计方法与分类规则-统计对象与服务识别与限制

> 本篇是《C5-01-统计方法与分类规则》的第1个分篇，主要包含：统计对象、服务识别、限制。

## 1-统计对象

- 题库题数：**719**
- 文本范围：题干 + 所有选项。

正确答案频率只读取 `correct_answer` 对应选项。

错误选项频率读取其余选项。
- 同一题同一服务在“总曝光”中最多计 1 次，避免一个选项重复写两次服务名导致虚高。
- 多选题例如 `AC` 会分别把 A 与 C 两个选项计入正确答案。

---

## 2-服务识别

使用项目服务词典做别名归一化，例如 `Amazon Elastic Block Store`、`Amazon EBS`、`EBS` 归入同一服务。

## 3-限制

这是基于题库文本的统计，不代表 AWS 官方考试权重。

服务别名和题目自然语言可能仍有少量漏计/误计，因此 C5 用于学习优先级而非官方蓝图。
