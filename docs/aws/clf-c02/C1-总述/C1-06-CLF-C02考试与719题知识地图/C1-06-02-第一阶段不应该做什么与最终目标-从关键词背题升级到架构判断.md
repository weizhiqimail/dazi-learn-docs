## 19-第一阶段不应该做什么？

在刚开始学习的时候，不建议：

```text
看到：
VPC Endpoint

马上背：
private access to S3
```

应该先理解：VPC是什么、为什么有Private Subnet、什么叫Internet、什么叫AWS Service Endpoint、为什么不希望经过公网。

然后：VPC Endpoint。

自然成为答案。

## 20-最终目标：从关键词背题升级到架构判断

初级状态：

```text
看到：
CPU
↓
CloudWatch
```

这对考试有帮助，但不够。

完整状态：

```text
题目说：
EC2实例CPU Utilization

↓
这是运行时性能指标
↓
需要Monitoring
↓
CloudWatch负责Metrics
↓
所以CloudWatch
```

再比如：

```text
题目说：
谁修改了Security Group？

↓
不是性能指标
↓
是AWS API activity
↓
需要audit trail
↓
CloudTrail
```

这才是稳定的知识。
