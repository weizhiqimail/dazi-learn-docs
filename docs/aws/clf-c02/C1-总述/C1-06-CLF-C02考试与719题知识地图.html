C1-06-CLF-C02考试与719题知识地图

1-CLF-C02-是什么？​

正式名称：AWS Certified Cloud Practitioner；考试代码：CLF-C02；级别：Foundational；中文可以理解为：AWS Certified Cloud Practitioner / AWS 云从业者基础认证

AWS 官方将它定位为验证对 AWS Cloud、AWS 服务和云术语的基础、高层次理解，而不是某个具体职位的深度技术认证。(Amazon Web Services)

2-当前考试形式​

截至当前 AWS 官方考试页面：

考试时间：
90 分钟

题目数量：
65 题

题型：
Multiple Choice
单项选择

Multiple Response
多项选择

级别：
Foundational

(Amazon Web Services)最低通过分数为：700 AWS 使用 scaled scoring（缩放评分），不是简单理解成：

“65 题答对 70% 就一定通过。”

(AWS Documentation)

3-★★★★★-官方四大考试领域​

当前 CLF-C02：

Domain中文权重
Domain 1: Cloud Concepts云概念24%
Domain 2: Security and Compliance安全性与合规性30%
Domain 3: Cloud Technology and Services云技术与服务34%
Domain 4: Billing, Pricing, and Support账单、定价与支持12%

(AWS Documentation)

4-为什么我们的教材不按照这四章直接学习？​

因为这四项是：

考试分类

而不是最佳学习顺序。例如：Availability Zone；会与：EC2、RDS Multi-AZ、High Availability、Disaster Recovery；产生大量关系。如果严格按照官方 Domain 切开：

Cloud Concepts学一点HA

几百页以后
Technology再学EC2

再后面
Database学RDS Multi-AZ

知识会碎掉。因此我们的教材采用：

第一阶段：
按技术体系学习

第二阶段：
按业务架构组合

第三阶段：
再映射回考试Domain

权重：34%；这是最大领域。官方当前 Domain 3 明确要求识别：AWS global infrastructure、AWS compute services、AWS database services、AWS network services、AWS storage services

以及部署和运营 AWS 的方式。(AWS Documentation)也就是说：EC2、S3、RDS、VPC、Route53、CloudFront、Lambda、DynamoDB、...；基本都集中在这里。

10-719-道题库的性质​

你的题库明确包含：719 questions并且题目从非常具体的服务题：Snowball Edge；开始。接下来立即进入：Inspector、Trusted Advisor、Config、GuardDuty；的安全服务对比。第三题又进入：Storage Gateway、S3、EBS、WorkSpaces；混合存储。第四题再进入：EC2、IAM、S3、Role、Least Privilege；这说明：

题库本身几乎没有适合学习的渐进顺序。

所以不能从 Q1 顺序学习到 Q719。

12-题库最有价值的不是“答案”​

题库真正有价值的四个维度：

12.1-发现高频知识​

例如 EC2、S3、IAM 等大量重复出现。

12.2-发现相似服务​

例如：CloudWatch、CloudTrail、Config、Trusted Advisor；经常一起作为选项。

12.3-发现考试语言​

例如：

most operationally efficient

most cost-effective

least operational overhead

highly available

scalable

without accessing the internet

fully managed

least privilege

这些条件经常决定答案。

12.4-发现旧知识​

题库中出现了一些当前 CLF-C02 已明确 Out-of-Scope 的服务。例如当前官方 Out-of-Scope 明确包括：AWS Wavelength、AWS CodeDeploy、Amazon WorkDocs、AWS IoT Device Defender、Amazon Personalize

(AWS Documentation)所以题库还是有“历史信息价值”，但备考优先级要调整。

14-Question-Bank-Answer-不等于-Official-Answer​

这是后面 Module 3 的基本原则。例如某些题会出现：Correct Answer；以及：Community vote distribution；两者可能不是完全一致。第一题就是明显案例：

题库：
Correct Answer = C

Community:
C = 84%
A = 16%

而评论里又有人基于不同理解支持 A。所以后续解析不会采用：

题库写C
↓
想办法证明C一定对

而是：

读题
↓
拆业务需求
↓
检查AWS当前定义
↓
逐项分析
↓
得出判断
↓
最后与题库答案比较

15-高频“技术服务题”与“概念题”​

CLF-C02 可以先理解成两类大题。

15.1-服务选择题​

例如：

A company wants to monitor EC2 CPU utilization.

你要识别：monitor、CPU、metric；→ CloudWatch。

15.2-云概念题​

例如：

系统可以承受故障并减少 downtime，体现了哪一个 Cloud Benefit？

题库第 77 题：Agility、Elasticity、Scalability、High Availability；正确方向是：High Availability。这类题不是 AWS Product Name。所以模块 1 既需要服务，也需要概念。

17-从官方-Domain-映射到教材章节​

官方 CLF-C02 Domain本教材主要对应内容

Cloud Technology and ServicesCompute、Storage、Database、Network、Monitoring、Analytics

但一个知识点可能同时服务多个 Domain。例如：AWS Organizations；既涉及：Governance；也可能出现在：Billing、Consolidated Billing；所以不会强行给服务贴唯一考试标签。

19-第一阶段不应该做什么？​

在刚开始学习的时候，不建议：

看到：
VPC Endpoint

马上背：
private access to S3

应该先理解：VPC是什么、为什么有Private Subnet、什么叫Internet、什么叫AWS Service Endpoint、为什么不希望经过公网；然后：VPC Endpoint；自然成为答案。
