# C2-01-01-本章目标

## 1-本章目标

这一章解决两个最基础的问题：

> **第一，为什么需要云计算？

**

以及：

> **第二，AWS 的“云”在现实世界里到底放在哪里？

**。

后续要学习的 EC2、S3、RDS、VPC、CloudFront、Route 53、Lambda 等服务，都建立在这一层基础设施之上。

本章将依次建立下面这套知识结构：

```text
传统数据中心
     │
     ▼
Cloud Computing
云计算
     │
     ├── Pay-as-you-go
     ├── Agility
     ├── Scalability
     ├── Elasticity
     ├── High Availability
     └── Economies of Scale
     │
     ▼
AWS Global Infrastructure
AWS 全球基础设施
     │
     ├── Region
     │     └── Availability Zone
     │
     ├── Edge Location
     ├── Local Zone
     ├── Outposts
     └── Wavelength（题库补充）
     │
     ▼
架构方式
     │
     ├── Single-AZ
     ├── Multi-AZ
     └── Multi-Region
     │
     ▼
Reliability / Resilience
可靠性 / 韧性
     │
     ├── High Availability
     ├── Fault Tolerance
     ├── Disaster Recovery
     ├── RTO
     └── RPO
```

这些不是零散的英语名词。

它们其实都在回答一个问题：

> **GlobalShop 怎样才能以合理的成本，让全球用户稳定地访问一个不会轻易挂掉、又能够随流量变化扩展的电商平台？

**。
