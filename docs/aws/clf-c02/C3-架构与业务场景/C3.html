C3-架构与业务场景

1-★★★★★-模块定位​

C3把C2中的单项AWS服务放入GlobalShop业务链路，通过需求、架构、数据流、安全、可靠性和成本约束解释服务为什么组合使用。

2-★★★★★-阅读主线​

  • GlobalShop完整基础架构
  • 用户访问商品页面完整链路
  • 订单异步化消息与事件驱动
  • Multi-AZ-Multi-Region与灾备
  • AWS高频服务选择决策树
  • 全体系易混服务对比

3-★★★★-学习标准​

能够从GlobalShop的业务需求推导服务组合，说明数据和请求的完整流向，并解释每项服务不能被相邻服务替代的原因。
