C3-17-全体系易混服务对比

资料口径：本模块以用户提供的 719 道 CLF-C02 题库与前序 C1/C2 项目资料为基础。题库的 correct_answer、社区投票与评论用于发现考点和争议，不自动等于当前 AWS 官方结论；本模块没有在生成过程中擅自用外部常识覆盖题库内容。凡现有项目已经明确标记为 [UPDATED]、[LEGACY]、[CURRENT-OUT-OF-SCOPE] 的内容，会继续保留这些状态提示。正式考试前，涉及当前产品状态和 Support 计划等时效信息仍应再对照 AWS 官方页面。

2-比较的正确方法​

不要比较“谁更高级”，而要比较：抽象层、数据模型、网络位置、是否有状态、是否用于运行时/审计/配置、是否面向组织还是 Workload。

3-六个比较轴​

3.1-抽象层​

EC2 管 VM；ECS/EKS 管容器编排；Fargate 管容器计算；Lambda 管函数执行。

3.2-数据模型​

S3=Object；EBS=Block；EFS/FSx=File；RDS/Aurora=Relational；DynamoDB=NoSQL；ElastiCache=Memory Cache。

3.3-网络位置​

IGW/NAT/Endpoint/Peering/TGW/VPN/Direct Connect 的差异来自“连接哪两端”。

3.4-安全动作​

Prevent、Protect、Detect、Investigate、Audit、Compliance 不是一个动作。WAF/Shield、GuardDuty/Inspector/Macie、Detective、CloudTrail/Config 应按动作拆开。

3.5-时间阶段​

Pricing Calculator 是 Before；CloudWatch 是 Runtime；Cost Explorer 是 After；Budgets 是 Threshold。

3.6-组织层级​

IAM 管身份权限；Organizations 管多 Account；CAF 管组织云采用；Well-Architected 管 Workload 架构。

4-最常见的错误比较​

  • 把“都是安全服务”当成可互换。
  • 把“都是托管服务”当成可互换。
  • 把“都能连接网络”当成可互换。
  • 把“都能保存数据”当成可互换。
  • 把“都能降低成本”当成可互换。

5-题库处理原则​

题库把大量相近服务放在同一道题的选项中。后续 C4 会对每道题按“题目目标 → 每个选项定位 → 题库答案 → 争议提示”进行分类解析。

6-复习方法​

先遮住右侧“核心区分”列，只看易混组合，要求自己用一句话说出差异；再到 C4 中找这些服务共同出现的题，验证是否真正理解。
