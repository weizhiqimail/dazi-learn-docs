## Q16-EC2计费与容量选择题

**题目：** An e-learning platform needs to run an application for 2 months each year. The application will be deployed on Amazon EC2 instances. Any application downtime during those 2 months must be avoided. Which EC2 purchasing option will meet these requirements MOST cost-effectively?

**选项：**

- A. Reserved Instances
- B. Dedicated Hosts
- C. Spot Instances
- D. On-Demand Instances

**主分类：** C4-04 EC2计费与容量选择题。

**题库记录答案：** `D`。

**需求/考点标签：** Cost Optimization。

**社区投票：** D 96%

### Q16.1-题干怎么拆

这道题先识别的不是某个服务名，而是这些约束：**Cost Optimization**。

### Q16.2-每个选项的定位

| 选项 | 题库内容 | 服务/概念定位 | 题库答案关系 |
|---|---|---|---|
| A | Reserved Instances | Reserved Instances：通过 1/3 年承诺获得折扣的 EC2/RDS 等预留定价概念，具体机制需按服务区分。 | 题库记录为非正确选项 |
| B | Dedicated Hosts | Dedicated Hosts：客户专用物理服务器，适合许可证/合规等硬件隔离要求。 | 题库记录为非正确选项 |
| C | Spot Instances | Spot Instances：利用 AWS 闲置计算容量的低价实例，但可能被中断。 | 题库记录为非正确选项 |
| D | On-Demand Instances | On-Demand Instances：无长期承诺、按使用付费的计算购买方式。 | 题库记录为正确选项 |

### Q16.3-为什么题库会这样选

题库记录的正确选项定位为：On-Demand Instances：无长期承诺、按使用付费的计算购买方式。
