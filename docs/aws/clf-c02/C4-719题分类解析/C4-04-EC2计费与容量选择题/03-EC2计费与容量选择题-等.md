**题目：** A company needs to continuously run an experimental workload on an Amazon EC2 instance and stop the instance after 12 hours. Which instance purchasing option will meet this requirement MOST cost-effectively?。

**选项：**

- C. Spot Instances
- D. Dedicated Instances
