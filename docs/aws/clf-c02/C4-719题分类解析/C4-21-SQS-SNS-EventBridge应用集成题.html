DAmazon ConnectAmazon Connect：云联络中心服务。题库记录为正确选项

Q710.3-为什么题库会这样选​

题库记录的正确选项定位为：Amazon Connect：云联络中心服务。。它与题干要求的对象/约束直接对应。其余选项虽然可能也属于同一大类，但主要解决不同问题。
